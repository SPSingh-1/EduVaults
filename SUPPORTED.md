# 📧 Contact Support

For general support, technical assistance, or product-related questions, please contact:

**Email:** spsrajjput@gmail.com

---

# 💬 Before Contacting Support

To help us resolve your issue more quickly, please include:

- EduVaults version
- Operating System
- Browser (if applicable)
- Steps to reproduce the issue
- Error messages or screenshots
- Relevant logs (if available)

---

# 🐞 Bug Reports

If you've found a bug that is **not security-related**, please create a GitHub Issue.

When reporting a bug, include:

- A clear description of the problem
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots (if applicable)
- Version information

---

# 🔒 Security Issues

If you've discovered a **security vulnerability**, **do not** create a public GitHub Issue.

Instead, report it privately via email:

**Security Contact:** spsrajjput@gmail.com

Please refer to **SECURITY.md** for our full security policy.

# ❓ Frequently Asked Questions

### Is EduVaults open source?

Please check the repository license for details.

### Which databases are supported?

Currently, EduVaults is designed to work with **Microsoft SQL Server**.

### Is EduVaults a multi-tenant application?

Yes. EduVaults is built with a secure multi-tenant architecture, allowing multiple schools to operate independently on the same platform.

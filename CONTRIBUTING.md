# Contributing to EduVaults

First of all, thank you for considering contributing to **EduVaults**! 🎉

We appreciate all contributions, whether it's reporting bugs, suggesting new features, improving documentation, or submitting code.

---

# Ways to Contribute

You can contribute by:

- Reporting bugs
- Suggesting new features
- Improving documentation
- Fixing bugs
- Improving UI/UX
- Optimizing performance
- Writing tests
- Refactoring code

---

# Getting Started

1. Fork the repository.
2. Clone your fork.

```bash
git clone https://github.com/YOUR_USERNAME/EduVaults.git
```

3. Create a new branch.

```bash
git checkout -b feature/your-feature-name
```

4. Make your changes.

5. Commit your changes.

```bash
git commit -m "Add: Short description"
```

6. Push to your branch.

```bash
git push origin feature/your-feature-name
```

7. Open a Pull Request.

---

# Pull Request Guidelines

Please ensure:

- Code builds successfully.
- No unnecessary files are included.
- Follow existing coding conventions.
- Keep Pull Requests focused on one feature or fix.
- Update documentation if needed.

---

# Reporting Bugs

Please include:

- Environment
- Version
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots (if applicable)

---

# Feature Requests

Feature requests should explain:

- The problem
- Proposed solution
- Expected benefit
- Additional context

---

# Coding Standards

- Write clean and readable code.
- Use meaningful variable names.
- Keep functions small and reusable.
- Add comments where necessary.
- Remove unused code before submitting.

---

# Code of Conduct

By participating in this project, you agree to follow our
**CODE_OF_CONDUCT.md**.

# Security

Please do **not** report security vulnerabilities through GitHub Issues.

Instead, follow the instructions in **SECURITY.md**.
